# LearnForge AI

LearnForge AI is an educational AI platform designed to help people truly understand knowledge instead of memorizing answers.

## Features

- Learn Mode
- Build Mode
- Improve Mode
- Troubleshoot Mode
- PDF Generation
- Gemini AI Integration

## Tech Stack

### Frontend
- Next.js
- React
- Tailwind CSS

### Backend
- FastAPI
- Python
- Gemini API
